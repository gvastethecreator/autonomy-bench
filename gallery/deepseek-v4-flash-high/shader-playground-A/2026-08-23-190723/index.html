Shader Playground — help

    

      
This is a live WebGL playground. A fullscreen quad renders one GLSL ES fragment
      shader on the canvas. The shader body you edit is wrapped in a hidden preamble that
      declares the uniforms below.

      
    
        
  • u_time — float seconds since the last time reset (accumulates while playing).
    • 
        
  • u_resolution — vec2 size of the drawing buffer in pixels (device-pixel aware).
    • 
        
  • u_mouse — vec2 normalized pointer position over the canvas, y points up (0…1).
    • 
        
  • u_frame — float frame counter (0, 1, 2, …).
    • 
      

      
Write a void main() that sets gl_FragColor. Typical start:
      
void main() {
  vec2 uv = (gl_FragCoord.xy * 2.0 - u_resolution) / u_resolution.y;
  float d = length(uv);
  gl_FragColor = vec4(0.5 + 0.5 * sin(d * 8.0 - u_time * 3.0));
}

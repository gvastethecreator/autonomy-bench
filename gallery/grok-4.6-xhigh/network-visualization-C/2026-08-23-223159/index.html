How to read the chamber

This is a working model, not a live network. Hierarchy is radial: control plane in the disc, super-cores next, then cloud on-ramps, regional halls, and edge PoPs on the outer orbit. Longitude sets the angle, so the Atlantic sits upper-left and the Pacific crosses the bottom.

Network inventory

Helios is a synthetic planetary backbone. Super-cores: Ashburn, San Jose, London, Frankfurt, Singapore, Tokyo. Control plane: anycast DNS, BGP route reflectors, PKI, orchestrator, telemetry, identity. Named long-haul systems include Potomac–Thames, Guadalupe–Uraga, Kallang–Main, Coral Run, and Cape of Glass. Traffic in the model follows local solar time, so load travels with daylight.

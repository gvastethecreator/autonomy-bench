      How the hollow stays alive

      This is one sealed nutrient pool. Plants grow only by taking soil. Grazing, hunting, and metabolism return waste to litter. Fungi and beetles mineralize litter back into soil. Roots and beetle larvae survive overgrazing. Foxes hunt poorly when voles are scarce, which usually leaves a remnant instead of a clean wipe. Extinction is still possible. If a lineage dies, release animals from soil matter — the jar’s total does not change.

How the dispatch works

  1. Hall call → score each car by ETA (distance + direction penalty + load + queue). Lowest score wins.
  2. SCAN (elevator) algorithm inside each car: serve all requests in current direction before reversing — no starvation.
  3. Lobby bias during morning: idle cars return to G.
  4. Doors 1.6 s dwell · full cars skip stops.
